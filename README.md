# Florist Catalog 🌷

Aplicação web desenvolvida para simular um catálogo digital de floricultura.

O projeto permite que clientes visualizem produtos, pesquisem flores, utilizem filtros por categoria, consultem detalhes dos produtos e adicionem itens ao carrinho.

A finalização do pedido é realizada pelo WhatsApp, enviando automaticamente para a floricultura os produtos e quantidades selecionados.

## Funcionalidades

- Catálogo de produtos
- Pesquisa por produtos
- Filtros por categoria
- Visualização detalhada de produtos
- Seleção de quantidade
- Carrinho de compras
- Integração com WhatsApp
- Integração com Instagram
- Google Maps
- Layout responsivo

## Tecnologias

- React
- Vite
- JavaScript
- Bootstrap
- CSS

## Status

🚧 Em desenvolvimento.

## Objetivo

O projeto foi desenvolvido como uma solução de catálogo digital para pequenos negócios do ramo de floricultura, permitindo que clientes conheçam os produtos antes de entrar em contato com a loja.

O site não realiza pagamentos diretamente. O pedido é montado pelo usuário e enviado para a floricultura através do WhatsApp.
